# Визуальные материалы

- `catalog-concept.png`: создан встроенным ImageGen. Запрос: русскоязычная библиотека «Переплёт», боковое меню, тёплый фон, зелёные акценты, книжная типографика, поиск и четыре колонки книг. Три согласованных экрана: каталог, бронирование, кабинет библиотекаря. Сгенерирован каталог; остальные экраны развивают его систему.
- Обложки: оригинальные геометрические SVG в `src/components/book-cover.js`, а не сканы реальных издательских обложек. Названия и авторы — метаданные книг.
- Иконки: собственный набор SVG-линий в `src/shared/icons.js`.
- Onest: Google Fonts, SIL Open Font License, `public/fonts/Onest-OFL.txt`.
- Lora: Google Fonts, SIL Open Font License, `public/fonts/Lora-OFL.txt`.

Растровые изображения не используются для отрисовки интерфейса. Приложение работает без внешних CDN и запросов к поставщикам картинок или шрифтов.
