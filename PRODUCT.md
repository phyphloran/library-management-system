# Переплёт

Учебное frontend-приложение библиотеки на HTML, CSS и JavaScript. Требования: три видовых экрана, адаптивность, анимации и рабочие пользовательские сценарии.

- Читатель находит книгу по названию, автору и ISBN, фильтрует по жанру и доступности, сохраняет избранное, просматривает описание и оформляет бронь.
- Читатель видит активные заявки и историю, может отменить ещё не выданную книгу.
- Библиотекарь подготавливает заявку, выдаёт книгу, принимает возврат, создаёт и редактирует записи каталога.

Это демонстрационная библиотека, не действующее учреждение. Каталог содержит начальные данные о восьми книгах; остатки экземпляров — учебные значения. Название «Переплёт» используется как название учебного проекта без заявления о коммерческом бренде.

Хранение: localStorage одного браузера и origin. Авторизации, сервера, отправки почты и изоляции разных читателей нет. Данные брони доступны тому, кто откроет учебный кабинет в этом же браузере. Для проверки следует использовать тестовые имя и почту.

Учебные правила: получение в ближайшие семь дней; возврат через 14 дней после выбранной даты получения; одна активная бронь каждой книги. Статусы: заявка → подготовлена → выдана → возвращена; отмена доступна до выдачи.
